7. WEBSITE FUNCTIONALITY (Feature-by-feature)
--------------------------------------------------------------------------------

----- 7.1 AUTHENTICATION -----
  - Register: Name, email, password, phone, DOB, gender. Password strong (uppercase, lowercase, number, special char). Email pe OTP bhejta hai.
  - Verify Email: 6-digit OTP enter karke email verify. 10 min valid.
  - Resend OTP: Naya OTP bhej sakte ho.
  - Login: Email + password. JWT token milta hai.
  - Login with OTP: Send OTP on email, OTP se login (password-less).
  - Forgot Password: Email bhejo, reset link/OTP.
  - Reset Password: Token se naya password set.
  - Logout: Token invalidate / client clear.
  - Profile: Get/update details, change password.
  - Protected routes: Login nahi hai to checkout, profile, orders, rewards pe nahi ja sakte.
  - Admin/Seller routes: Role check - sirf admin ya seller hi enter kar sakta hai.

----- 7.2 HOMEPAGE -----
  - Cinematic Hero: Hero section (sliders se ya static).
  - Featured Brands: Brands list (API se).
  - Shop by Category: Categories carousel.
  - Most Loved Brands: Brands section.
  - New Arrivals: Featured products (8).
  - Offers For You: Offers section.
  - Why Buy From Us: USPs.
  - Celebrity Look: Content section.
  - Inspiration Section: Content.
  - Explore Boutiques: Boutiques link/section.
  - Spotted With JIT: Section.

----- 7.3 PRODUCTS -----
  - Product listing: Pagination, filters (category, brand, search).
  - Product detail: Single product, images, price, description, add to cart, add to wishlist.
  - Categories: Category se filter, slug se URL.
  - Search: Search term se products.

----- 7.4 CART -----
  - Add to cart: Product/variant, quantity. (Login optional - agar guest hai to bhi cart local/API se)
  - Cart drawer: Side drawer me cart items, quantity update, remove.
  - Cart page: Full page cart, update quantities, remove, proceed to checkout.

----- 7.5 WISHLIST -----
  - Add/remove wishlist: Login required (API).

8. DATA FLOW (Basic se pura flow)
--------------------------------------------------------------------------------

1) User site kholta hai -> HomePage load -> Sliders, categories, brands, featured products API se aate hain.

2) Product browse -> ProductListPage -> /api/products (filters, pagination) -> ProductCard click -> ProductDetailPage -> /api/products/:id.

3) Add to cart -> POST /api/cart (login required) -> Cart state update (Redux) -> Cart drawer / Cart page me dikhega.

4) Wishlist -> POST/DELETE /api/wishlist -> Wishlist slice update.

5) Checkout -> Login check -> CheckoutPage -> Shipping/billing form -> POST /api/orders (cart items, address, payment method) -> Backend: cart read, stock check, order + order_items + addresses insert, payment method (e.g. COD) -> Response order detail -> Redirect/order success. Cart clear (backend/frontend).

6) Orders -> GET /api/orders -> OrderHistoryPage. Order click -> GET /api/orders/:id -> OrderDetailPage. Cancel -> PUT /api/orders/:id/cancel. Receipt -> GET /api/orders/:id/receipt (PDF).

7) Register -> POST /api/auth/register -> Backend user insert, OTP email -> User OTP enter -> POST /api/auth/verify-email -> Email verified. Login -> POST /api/auth/login -> JWT -> Frontend token save (localStorage) -> Headers me Authorization.

8) Admin login -> /admin -> AdminRoute role check -> Admin layout + sidebar -> Dashboard, Products, etc. Product add -> form (name, price, images, ...) -> POST /api/admin/products. Image: ya to URL daalo ya file upload -> POST /api/admin/upload -> URL milta hai -> wahi product images me use. Same Categories, Brands, Sliders me ImageInput (URL ya upload).

9) Sliders homepage pe: GET /api/sliders/active -> CinematicHero/HeroSection me use.
